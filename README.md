## Security & systems

Cybersecurity is not separate from software engineering for me. I am interested in understanding what happens underneath an application:

- How computers communicate across networks
- What ports and protocols actually represent
- How authentication and authorization should work
- How applications expose attack surfaces
- How insecure configuration creates vulnerabilities
- How to inspect systems and reason about unexpected behavior
- How defensive engineering changes application design

My security work is conducted as **authorized coursework, CTFs, and controlled labs**.

## Engineering mindset

```text
Problem
  ↓
Requirements
  ↓
Data + constraints
  ↓
Break the problem into smaller parts
  ↓
Implement
  ↓
Test
  ↓
Debug
  ↓
Secure
  ↓
Document
  ↓
Improve
```

When I get stuck, the goal is not simply to find the next piece of syntax. The goal is to identify **which part of the mental model is missing**.
